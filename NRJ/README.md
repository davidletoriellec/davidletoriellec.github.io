# TP Puissance et énergie – v1

Application web autonome (un seul fichier `index.html`) pour des TP d’électricité :

1. **Étude sur les lampes** : mesures U, I, P (incandescence 60 W, LED 9 W, cos φ = 0,83), puis étude de rentabilité LED / incandescence.
2. **Étude sur le four** : four de 1500 W avec régulation tout ou rien, courbes de température et de sortie TOR, zoom, mesures U et I.

Export PDF (nom, prénom, groupe, questions traitées et réponses).

## Utilisation

- Ouvrir `index.html` dans un navigateur, ou l’héberger avec GitHub Pages.
- **Mode prof (corrigé)** : ajouter `#prof` à l’adresse, par exemple `https://<compte>.github.io/<depot>/index.html#prof`.
- L’export PDF utilise jsPDF, chargé depuis cdnjs : une connexion Internet est nécessaire.
